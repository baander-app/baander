# Administration

Use user management for account creation and access changes. Account recovery and
session revocation have different effects; check the relevant guide before using
them to restore access or respond to an exposed credential.

| Guide | Scope |
|-------|-------|
| [User Management](user-management.md) | Create accounts, assign roles, change settings and disable or delete users |
| [Account Recovery](account-recovery.md) | Manage passkeys, TOTP 2FA, password resets and email verification |
| [Sessions and Access](sessions-and-access.md) | Understand session revocation, account disablement and Redis outages |
| [OAuth Clients](oauth-clients.md) | Register and administer client applications |
| [Notifications](notifications.md) | Browser push notifications (VAPID), HMAC-signed webhooks, SMTP email delivery, health alerts, and delivery diagnostics |
| [Registry](registry.md) | Provisioning, operating, monitoring, and backing up the optional C++ server-discovery registry |
