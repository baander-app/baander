# Media and Playback

Manage your music and video libraries, configure optional external metadata and lyrics enrichment, tune original and transcoded media delivery, and run synchronized watch parties.

| Guide | Scope |
|-------|-------|
| [Library Management](library-management.md) | Creating libraries, scanning media, inotify file watching, supported audio/video/subtitle formats, and cover art extraction |

| [Transcoding](transcoding.md) | Original playback vs CMAF/HLS/DASH video and audio transcoding, quality tiers, worker execution slots, VAAPI hardware acceleration, and bAAC |
| [Watch Parties](watch-parties.md) | Synchronized playback sessions, participant membership, host controls, and real-time WebSocket coordination |
