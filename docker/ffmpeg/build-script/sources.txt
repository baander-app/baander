# Every source ffmpeg-build-script v1.59 builds from in this image, in the order the
# script uses them. fetch-sources.sh places each file in the script's packages
# directory before the script runs, and the patched script refuses to download a
# file that is missing here.
#
#   <file> sha256:<hash> <url>          downloaded, then checked against the SHA-256
#   <file> git:<commit> <repository>    fetched at the commit and archived under one
#                                       top-level directory, or none with "flat"
#
# Archives that a forge generates on request (GitLab, Gitiles, Bitbucket) are not
# byte-stable, so those sources are pinned by commit, as are the dependency trees
# that libjxl's deps.sh and glslang's update_glslang_sources.py would fetch at build
# time. After a script bump, list its download calls for the enabled components
# again and take each new archive's SHA-256 and each new commit.
